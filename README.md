# Drover — releases

Signed Android APKs of **Drover**, an app for driving Claude Code agents that run in herdr / herdr-core terminals on your own machine over SSH.

Download the newest `drover-x.y.z.apk` from **[Releases](../../releases/latest)** and install it over the previous version (same signing key).
